# Jmeter
Repositório para gravar testes de performance com a ferramenta Jmeter

Cenário testado: Busca parametrizada no YouTube utilizando CSV Data Set Config (youtube_mass.csv).   Configuração do Thread Group: Quantidade de usuários virtuais (threads), ramp-up e loop count.Listeners / Métricas analisadas: Tempo de resposta médio, vazão (throughput) e taxa de erro.
